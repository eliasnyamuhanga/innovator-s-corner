INNOVATOR'S CORNER — KONA YA WABUNIFU

Files:
- index.html: complete single-file website (HTML, CSS and vanilla JavaScript).

SETUP BEFORE PUBLISHING
1. Open index.html in a text editor.
2. Find: const WHATSAPP_NUMBER = "255XXXXXXXXX";
3. Replace 255XXXXXXXXX with the organizer's Tanzanian WhatsApp number in digits only.
   Example format: 255712345678 (do not include +, spaces, or a leading 0).
4. Save and open index.html in a browser.

NOTES
- The page defaults to English. EN/SW changes all interface text and the WhatsApp message.
- Language choice is held in JavaScript memory only; it is not saved to browser storage.
- Submitting opens WhatsApp with a pre-filled message. The user must press Send in WhatsApp.
- The illustration is inline SVG; there are no image files or JavaScript libraries.
- Google Fonts are optional network requests. System font fallbacks are included.
